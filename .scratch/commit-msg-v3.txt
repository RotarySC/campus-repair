feat(web): 资产线第二批 —— V3 的 12 个故障分类图标

规范 §4.6 的 V3：把「纯文字分类树」换成分类图标。

## 键怎么选（这是 V3 与 V4 最大的差别）

V4 的键是闭集（DB 的 level_type，1~4），V3 的键不是（repair_category.name
是自由文本，用户可新建/改名）。两条被否决的路：

- 按 id：那是演示数据的自增值，用户新建一条就没有；且 id 在 test/demo/生产
  三套环境里不保证一致，写进前端等于把种子数据的偶然编号变成契约。
- 只按 worker_skill_code：它确实是闭集（5 个），但分不开同胞——
  水龙头漏水与下水道堵塞的工种都是 PLUMBER，按它取会拿到同一个图标。

于是取键是一条链：分类名 → worker_skill_code → 空。第二级不是装饰，它让
「用户新建的细类」仍然有图标而不是空白；第三级沿用 LevelIcon 的约定：
取不到就什么都不渲染，不画「未知」占位图形。

数据表抽到 components/categoryIcons.ts（纯数据），CategoryIcon.vue 只负责渲染。
额外好处：探针可以从 Vite 模块图里 import 到真实路径出联表图，不必抄一份 d 字符串。

## 12 个图标里有 4 个是画错重画的

图标是画出来的：路径合法、尺寸对、颜色可继承——类型检查、几何断言、计数断言
全都看不出一个图形长得像不像它要表示的东西。第一版 4 个认不出，靠联表图发现：

- 水暖管道 → 一个 # 井号（两条等长横线 × 两条等长竖线，处处相交）
  → 改弯头（连续外壁 + 连续内壁 + 两个断面）
- 下水道堵塞 → 一辆带轮子的推车（横向栅板当车身、波纹当轮子）
  → 改漏斗（有了往下收的形态）
- 暖通空调 → 一个文本框（两道气流一长一短且都偏左）
  → 两道都居中、长→短收束
- 插座跳闸 → 框里一个 !（三条笔画都竖着且对称）
  → 改三孔布局；这一版改了两轮，第二轮还是「一张脸」

联表图脚本入库：.scratch/sheet-category-icons.mjs

## 第五处「四个装饰色」同族缺陷

分类表/卡片的层级标签是 :type="level===1 ? 'primary' : 'success'"——
大类=蓝、二级细类=绿，与 §17.3 删掉的 getLevelTagType() 逐字同病：
层级是分类，不是状态；success 在这里表示的是「这是二级的」而不是「这是好的」。
换成中性发丝线 chip（.category-level-chip）。

注意 el-tag 不传 type 不是中性——默认值就是 primary，想真中性必须换元素。
同页的「指派维修工种」type="warning" 没有动，属已被搁置的那批彩色控件。

## 看图上抓到第 5 个缺陷，而它是 V4 引入的

.dd-option 是 justify-content: space-between，而 .dd-option__label 没有 flex。
两子元素（标签+箭头）时恰好正确；V4 加进第三个子元素（层级图标）之后，
space-between 把中间那个也参与分配，标签被推到行的正中央，空出约 150px。

V4 的探针只数了「几行有图标」——图标在不在，和排得好不好是两件事——
所以它一路绿着通过了 V4 的验收。

修法 .dd-option__label { flex: 1 1 auto }：两子元素与三子元素都正确，
且两子元素时的几何与改动前逐像素相同（既有 4 个调用方无感）。

新增断言「图标右沿 → 标签左沿 ≤ 16px」并带反向自证（把 flex-grow 用
!important 掐回 0，间距必须变大）：正常 8px → 掐回后 125px。

## 量具又错了一次：EP 的 el-input 会静默吞掉同值输入

⑧ 第一次跑是 SKIP。先直连 API 证了同一句话返回 2 条候选（后端没问题），
才敢断定是探针的问题。根因：

  // el-input 的 handleInput
  if (value === nativeInputValue.value) { setNativeInputValue(); return }  // 不发 input

提单页会把草稿回填进描述框，于是「再输一遍同样的文字」是静默空操作。
更细的一层：先清空再输入时两次赋值不能挤在同一 tick——nativeInputValue 是
el-input 内部 ref、由 watcher 更新，同步写完 '' 再写新文字时第二次比较读到
的还是旧草稿，而那恰好等于新文字，又走到 early return。中间必须隔一拍。

## 新增回归 .scratch/check-category-icons.mjs（13 条）

其中 ③「12 个图形互不相同」最值钱：V3 是 12 个手画路径，最容易出的错是
复制粘贴之后只改了名字没改路径——那样 12 个图标长得一模一样，
而它通不过任何类型检查，也通不过「行数对不对」的计数断言。
