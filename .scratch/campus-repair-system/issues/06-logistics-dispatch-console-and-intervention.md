# 06 — 调度中心人工干预控制台与改派作废

**What to build:** 交付后勤管理员专用的桌面调度中心双栏分屏工作台。左栏展示待办调度池工单列表，支持按智能派单失败、师傅申请转派、加急异常工单及返工待派等分类快速过滤，对返工和加急单给予强烈视觉警示；右栏根据左侧所选工单的工种与校区需求，联动高亮展示对应师傅的在岗状态、实时负载彩色进度条（如绿色未满、橙色临界、红色已满）及近期战绩；调度人员可在同屏内直接点击卡片完成秒级人工指派或强制改派，无需弹窗反复跳转；同时提供工单核实作废功能（必须录入作废原因，状态变为 `CANCELLED`）。

**Blocked by:** 05 — 智能规则自动派单引擎与并发防超派

**Status:** completed

- [x] 调度中心待办工单池分页检索与多维度分类过滤接口落地（包含派单失败、申请转派、加急单与返工单）
- [x] 师傅在修负荷、出勤状态与战绩实时视图接口就绪
- [x] PC 管理端调度中心双栏分屏界面落地，左栏支持工单卡片列表选择，右栏联动展示匹配工种的师傅负荷看板与彩色进度条
- [x] 调度人员一键人工指派/强制改派功能落地，成功更新工单指派信息并推进状态为 `ASSIGNED`，记录流转日志
- [x] 虚假或无效工单核实作废功能落地，强制要求输入作废原因并将工单变更为 `CANCELLED` 终止流转
- [x] 编写测试用例验证调度池筛选准确性、人工指派合法状态流转及作废状态拦截逻辑
