# 05 — 智能规则自动派单引擎与并发防超派

**What to build:** 实现报修提单后的规则自动化派单算法与高并发防超派防护机制。系统监听工单提交事件后，自动提取工单所需工种与所属校区，从在岗人员档案中筛选出符合工种技能、所属校区匹配、考勤状态在岗且当前未满载的师傅候选人，按当前在修负荷最小优先（若负荷相同则按服务评分最高优先）进行精准指派；在派单决策过程中引入分布式锁对候选师傅施加排他互斥，并在锁内执行双重负载校验，杜绝极端高并发提单瞬间将大量工单指派给同一位师傅而突破最大并发负载（`max_load`）的问题；自动指派成功后工单流转为待承接（`ASSIGNED`），若无匹配候选人或全员满载，则优雅降级为待人工调度（`MANUAL_DISPATCH`）并记录审计日志。

**Blocked by:** 02 — 人员台账维护、Excel 批量导入与资料维护, 04 — 师生极速报修提单、防重预警与客户端防丢草稿
