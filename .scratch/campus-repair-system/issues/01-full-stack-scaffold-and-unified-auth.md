# 01 — 全栈工程底座与多端统一安全认证

**What to build:** 为整个校园报修系统建立前后端双端工程底座与统一身份认证体系。支持使用学号、工号或手机号作为登录凭据，对连续输错 3 次密码的情形强制弹出图形验证码校验防暴力破解。系统采用无状态双 Token 认证（2 小时短效 Access Token 与 7 天长效 Refresh Token），前端网络客户端自动处理 HTTP 401 错误并在后台使用刷新令牌静默换票重试，无需用户手动重新登录。交付 PC 管理端与移动端各自适配的登录视图及跨端会话保持机制。

**Blocked by:** None — can start immediately.

**Status:** resolved
