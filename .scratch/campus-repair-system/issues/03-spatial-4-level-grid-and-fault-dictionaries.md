# 03 — 校园四级空间网格与两级故障分类字典

**What to build:** 建立校园物理空间网格体系与报修故障两级分类字典标准。支持“校区 -> 区域组团 -> 楼栋 -> 楼层房间”四级树状空间结构，支持为楼栋标记建筑性质（宿舍/教学/办公/场馆）并指派网格责任人，支持历史网格节点的软停用（停用后历史单据可读但提单不可选）；建立两级故障分类树（大类与细类），细类直接映射标准维修工种编码与 SLA 预估时效（小时）；提供全局业务运行规则与参数配置管理面板（如 72 小时超时核销、2 星差评阈值等）。

**Blocked by:** 01 — 全栈工程底座与多端统一安全认证
