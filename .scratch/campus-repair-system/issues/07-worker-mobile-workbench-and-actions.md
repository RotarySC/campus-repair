# 07 — 维修师傅移动自适应作业台与挂起转派

**What to build:** 交付维修师傅专属的移动自适应 H5 工作台。页面顶部提供粘性切换的三栏卡片流：【待承接】展示新分派任务，内置直观的拨号协议按钮支持一键外呼联络报修人，点击【接单出发】将工单状态推进至维修中（`IN_PROGRESS`）并记录出发时间戳；【维修中】展示进行中任务，支持现场突发缺料或外协阻滞时的异常【挂起】操作（录入原因与预计恢复时间，系统同步暂停 SLA 计时），支持缺料解决后的【解除挂起】恢复施工；现场排查判定超出自身技能范围时，支持发起【申请转派】（说明原因并推荐工种，工单移回人工调度池并移出师傅个人负荷）；【历史记录】用于查阅已完工历史工单与评价结果。

**Blocked by:** 05 — 智能规则自动派单引擎与并发防超派
