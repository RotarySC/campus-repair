# 09 — 完工验收、质检评价与差评返工仲裁闭环

**What to build:** 建立维修完工后的师生质检验收、服务满意度评价、系统 72 小时超时自动核销以及差评返工闭环机制。师生在移动端查看报修前后现场实况对比卡片（Visual Diff，左侧报修原图、右侧完工水印图），核验无误后提交 1~5 星满意度打分与标签评语，打分 >= 3 星工单直接闭环结单（`COMPLETED`）；若师生提交 <= 2 星差评并指明未修好，系统立即阻断结单，将工单状态置为返工待派（`REWORK_PENDING`），并在后勤调度中心标红置顶；后勤主管介入核实仲裁，可决策退回原师傅限期整改或换派资深技师；同时系统配置定时任务扫描超过 72 小时师生未主动确认的待验收工单，自动执行超时验收结单。

**Blocked by:** 08 — 完工填报、防伪时间水印与耗材出库防超卖
