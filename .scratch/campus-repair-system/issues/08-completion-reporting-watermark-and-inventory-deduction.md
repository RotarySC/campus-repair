# 08 — 完工填报、防伪时间水印与耗材出库防超卖

**What to build:** 交付师傅现场完工填报、现场照片防伪水印压制及物料核销扣减出库全流程。师傅在移动端填写维修总结，拍摄或上传 1~3 张现场完工照片，客户端 Canvas 自动将工单编号、作业师傅姓名及当前时间戳压制为半透明防伪水印层；若本次维修消耗了库房物料，可在物料核销面板中搜索添加备件，步进器输入数量受到物理库存的硬上限约束，实时计算单工单直接耗材成本；提交完工时，后端执行数据库带条件的行级原子更新（`UPDATE spare_part SET stock_quantity = stock_quantity - ? WHERE id = ? AND stock_quantity >= ?`），防范多名师傅同时核销同一紧俏耗材导致的库存穿透超卖；完工提交成功后，工单状态流转为待验收（`PENDING_ACCEPTANCE`）并记录完工时间。

**Blocked by:** 07 — 维修师傅移动自适应作业台与挂起转派
