# 11 — 耗材备件进销存台账、安全库存预警与采购建议

**What to build:** 为后勤物资管理人员构建轻量级耗材备件进销存台账体系。支持水暖管件、电工电气、门窗五金等各类备件的编码、规格型号、计量单位、指导单价及物理库存的维护与分页查询；提供采购入库登记功能，录入批次、单价与数量并自动累加物理库存，沉淀不可篡改的入库流水；在备件实际库存低于或等于设定的安全库存阈值时，后勤界面顶部常驻红色告警横幅提醒补货，并支持一键流式导出待采购建议清单 Excel，打通现场报修消耗与仓库物资补齐的全生命周期。

**Blocked by:** 08 — 完工填报、防伪时间水印与耗材出库防超卖

**Status:** ready-for-agent

- [ ] 耗材采购入库明细流水数据表建立
- [ ] 后勤 PC 管理端耗材备件台账维护界面落地（支持分类 Tab 切换、规格单价维护、状态上架/停用）
- [ ] 采购入库登记功能与表单落地，在单笔事务中完成入库明细流水插入与备件物理库存累加
- [ ] 安全库存预警机制就绪，列表实时标红低库存记录，并在管理端页面顶部展示聚合告警提示条
- [ ] 基于 EasyExcel 提供缺料采购建议清单一键流式导出，自动计算推荐采购参考数据
- [ ] 编写测试用例验证入库事务库存累加正确性、低库存告警判定准确性及采购建议数据导出格式
