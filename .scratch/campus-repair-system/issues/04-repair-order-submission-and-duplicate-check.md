# 04 — 师生极速报修提单、防重预警与客户端防丢草稿

**What to build:** 交付面向师生的极速移动报修提单功能与提单前防重复预警机制。系统在用户进入提单页时自动带出个人默认报修地址，提供四级空间级联选择抽屉与带图标的故障分类选择卡片；在用户选定空间与分类后，自动异步检测该位置是否存在尚未结单的同类故障单，若存在则在表单中部弹出温和预警，避免学生重复提单；支持现场拍摄或选取 1~3 张损坏照片，采用客户端 Canvas 自动完成等比缩放与有损压缩以减少弱网上传耗时；提供预约时段与紧急度选项；实时保存表单输入至本地草稿，在异常刷新或断网时支持自动提示恢复；提交成功后生成唯一的 `BX` 格式业务单号并发布提单领域事件。

**Blocked by:** 01 — 全栈工程底座与多端统一安全认证, 03 — 校园四级空间网格与两级故障分类字典

**Status:** resolved

- [x] 全局递增业务流水单号生成服务就绪（按 `BX` + 年月日 + 6 位序列格式）
- [x] 同空间同分类未结单活跃工单异步防重检测接口完成，移动端实现防抖并能动态展示预警条与既有工单指引
- [x] 移动端极速提单界面落地，支持个人默认住址自动填充、空间抽屉切换及分类可视化选择
- [x] 现场照片上传前客户端 Canvas 自动尺寸重采样与压缩处理落地，显著降低上传带宽消耗与等待时间
