# 02 — 人员台账维护、Excel 批量导入与资料维护

**What to build:** 交付系统各角色人员台账的统一维护能力。面向学生与教职工提供前台自主激活注册功能（严格校验学号/工号及手机号码的唯一性）；面向后勤与系统管理人员提供基于 Excel 的万人级人员名单批量导入解析，对格式不合法或重复数据进行精准定位并生成带行号的错误报告；支持初次登录强制修改初始密码，并允许用户在个人中心维护常用联系方式与默认绑定的物理空间地址。

**Blocked by:** 01 — 全栈工程底座与多端统一安全认证
